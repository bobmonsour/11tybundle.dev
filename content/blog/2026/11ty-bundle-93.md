## Highlights

**Build Awesome (11ty) v4.0.0.0 alphas.** Zach has put out a couple of new alpha releases of Build Awesome (11ty) with [Build Awesome (11ty) v4.0.0-alpha.9](https://github.com/11ty/buildawesome/releases/tag/v4.0.0-alpha.9) being the big one. alpha.10 is a small fix, so check out those release notes for details.

**One markdown file to multiple output files.** [Alex Russell](https://infrequently.org/) has released a plugin for "_generating multiple output documents from a single markdown file"_. I've seen several requests for this kind of thing, so this is a welcome addition to the 11ty ecosystem. Check out [eleventy-plugin-multidoc](https://github.com/slightlyoff/eleventy-plugin-multidoc) for details.

**Adam has caught fire.** [Adam DJ Brett](https://www.adamdjbrett.com) has been on a tear, generating 8 posts over the last few weeks. Head to his [author page](/authors/adam-dj-brett/) for all of his posts. But here's a quick list for this issue:

- [Easier Font Awesome SVGs in 11ty](https://www.adamdjbrett.com/blog/easier-11ty-font-awesome-svg/) — how to use the @11ty/font-awesome plugin to convert Font Awesome web fonts into inline SVGs during the Eleventy build process.

- [How to Implement status.lol on BuildAwesome](https://www.adamdjbrett.com/blog/how-to-implement-status-lol-on-11ty/) — implementing a GitHub Actions workflow that automatically posts new blog entries to status.lol.

- [How Build Awesome alpha, async Nunjucks, and smaller Cloudflare checks fixed my podcast build](https://www.adamdjbrett.com/blog/2026-07-05-build-awesome-cloudflare-optimization/) — optimizing his podcast website's build pipeline by upgrading to Build Awesome alpha, implementing async Nunjucks, and reducing unnecessary Cloudflare checks, significantly improving deployment speed.

- [Making Static Sites FAIR with metadata.json, Zotero, Eleventy, and Jekyll](https://www.adamdjbrett.com/blog/fair-signposting-metadata-json-eleventy/) — how to implement FAIR signposting and metadata.json files in static sites built with Eleventy and Jekyll to make scholarly content machine-readable for citation managers and discovery systems.

- [Xmit Might Be My New Favorite Static Site Host](https://www.adamdjbrett.com/blog/xmit-vs-netlify-vercel-render/) — discusses his preference for Xmit as a static site host because it offers simple, fast deployment without requiring workflow reorganization.

- [Publishing Your Eleventy Blog on the AT Protocol with Standard.site and Sequoia](https://www.adamdjbrett.com/blog/standard-site-eleventy-sequoia/) — how to publish an Eleventy static site on the AT Protocol using Standard.site and Sequoia.

- [Enabling Webmentions in Eleventy (11ty)](https://www.adamdjbrett.com/blog/enabling-webmentions-in-11ty/) — implementing webmentions on his Eleventy site to display social media interactions and replies using open web standards.

- [11tyx5: Five Whitestone Foundation Sites, Eleventy, and the Long Open Web](https://www.adamdjbrett.com/blog/11tyx5-five-sites-long-web/) — rebuilding five Whitestone Foundation academic publishing sites using Eleventy to create a durable, long-term publishing infrastructure based on plain files and open web standards.

**Brennan also remains prolific.** [Brennan Kenneth Brown](https://brennan.day) has continued to grace us with deep dives into the processes he uses to flesh out his site. Here are his latest two posts:

- [Publishing My Eleventy Blog to the ATmosphere with Standard.site](https://brennan.day/publishing-my-eleventy-blog-to-the-atmosphere-with-standard-site/) — integrating the AT Protocol and Standard.site into an Eleventy-based blog to publish long-form content to Bluesky's decentralized network.

- [How Webmentions Work on brennan.day](https://brennan.day/how-webmentions-work-on-brennan-day/) — how webmentions enable cross-site interactions on static blogs, using webmention.io as an intermediary service to receive and display likes, replies, and mentions from other websites.

**Using AI to diagnose performance issues.** [Raymond Camden](https://www.raymondcamden.com) used AI to uncover performance improvement opportunities for his blog in [Asking Cursor to Review My Blog for Performance](https://www.raymondcamden.com/2026/07/07/asking-cursor-to-review-my-blog-for-performance).
